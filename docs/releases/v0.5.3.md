# Milo v0.5.3 · YouTube 原位中文字幕

按用户需求，YouTube 直接沿用原来的字幕位置与样式，只显示中文。

- 优先使用已有中文字幕轨；没有时尝试平台自带自动翻译。
- 不逐句调用 DeepSeek，不需要 AI 密钥，避免滚动字幕变化导致请求反复取消与译文迟到。
- 不隐藏原字幕区，不生成额外字幕浮层；字体、颜色、位置与时间轴由 YouTube 管理。
- 关闭时恢复之前的字幕语言与 CC 状态；尊重手动修改，视频切换后不恢复旧视频轨。
- 通过 Chrome scripting MAIN 环境调用播放器；开始 / 关闭按文档顺序执行，避免快速点击后状态错乱。
- X 仍使用原有双语字幕翻译链路。

174 项自动测试、lint、类型检查与构建通过。真实扩展在隔离 Chromium 验证原位中文、现成 / 自动翻译轨、快速字幕变化、快速开关、容器全屏和 X 回归。结构测试使用固定示例。

真实公开 YouTube 视频已验证播放器轨读取、原生中文字幕切换与 CC 恢复。但匿名环境的字幕请求返回 HTTP 200 空内容，字幕实际渲染尚未完成真实视频端到端验证；不绕过平台限制。播放器内部接口随平台更新可能变化。

新增 scripting 权限，用于 YouTube 当前文档的原生字幕控制，不读取账号、不发送密钥、不执行任意用户脚本。更新后重新加载扩展，并刷新 YouTube 页面。
