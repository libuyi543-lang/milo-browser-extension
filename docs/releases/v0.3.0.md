# Milo v0.3.0 · 四种 AI 服务，自由切换

- 新增 DeepSeek、智谱 GLM、小米 MiMo、MiniMax 配置入口。
- 每家独立保存 API Key 与模型，保存后划词和正文翻译同时生效。
- 新增「保存并测试」、模型选择 / 编辑、获取密钥链接与移除单家密钥。
- 旧 DeepSeek 配置与单词本保留；切换服务取消旧请求，缓存按服务隔离。
- Milo 图标进入设置，增加 Chrome 工具栏固定说明。

## 使用

下载并解压下方 ZIP，Chrome 128+ 在 `chrome://extensions` 加载包含 `manifest.json` 的目录。更新现有安装时覆盖原目录、重新加载并刷新页面，避免卸载导致本地数据丢失。

Chrome 右上角拼图 → Milo → 图钉，可固定图标。点击 Milo →「管理 API」→ 选服务 → 填密钥与模型 →「保存并使用」。

[配置说明与展示](https://github.com/libuyi543-lang/milo-browser-extension/blob/main/docs/AI_PROVIDERS.md)

API 费用由所选服务账户承担。「保存并测试」会发送一次 hello 请求。MiniMax 当前使用中国站普通 API 端点；国际站 / 订阅专用端点与自定义 URL 尚未接入。
