# Milo v0.3.1 · 修复工具栏空白窗口

修复新 popup 读取仍在运行的旧后台设置时，缺少 `profiles` 字段导致整个界面崩溃的问题。

- 设置响应校验，版本失配显示明确的「重新加载」说明。
- 提供打开扩展管理、重新读取设置入口。
- 增加 popup 错误边界，异常时保留可操作界面。
- 不改变原有密钥与单词本。

## 更新

下载并解压 ZIP，覆盖原扩展目录。在 `chrome://extensions` 点击 Milo「重新加载」，再点击工具栏图标。为保留本地数据，请使用重新加载更新。

115 项单元测试、lint、type-check、build 通过。另在真实 Chromium 临时配置中加载扩展，验证新后台正常打开，以及旧后台 / 新窗口不再空白。没有使用用户浏览器资料或真实 API Key。
