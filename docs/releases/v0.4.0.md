# Milo v0.4.0 · 三下空格，输入框中文变英文

输入中文后快速连续敲三下空格，Milo 使用当前 AI 服务，将当前输入框的完整内容翻译成英文并原位替换。无需选择文字或点击按钮。

- 前两下为普通输入，第三下触发后移除快捷键空格。
- 使用当前 DeepSeek / 智谱 / 小米 MiMo / MiniMax 配置。
- 编辑、切换焦点、Escape 会取消旧任务，保护新的输入内容。
- 跳过纯英文、密码、只读、输入法选字及长按空格。
- 支持普通搜索框、input、textarea 与基础 contenteditable；当前限 2000 字符，敲击间隔不超过 1.2 秒。
- 原有划词、保存、正文翻译与 API 配置保留。

下载 ZIP 后解压覆盖原目录，在 `chrome://extensions` 重新加载 Milo，并刷新网页。数据与密钥保留。

140 项测试、lint、type-check、build 通过。另使用真实 Chromium 扩展与本地模拟 AI 响应，验证原位替换、撤销、React 状态、继续编辑保护和原有功能。
