# Milo v0.5.0 · 桌面翻译工作台

这一版继续完善电脑端：正文阅读、输入表达、文件、图片、字幕与词库都集中到一个工作台。手机端和在线会议暂不包含。

## 新增

- 文本工作台，100 多种语言选项；原文语言、输入目标语言、双语 / 仅译文、四种译文样式、自动 / 排除网站与 AI 术语表。
- Control 悬停段落翻译；动态正文自动续译，已更新段落不重复堆积，恢复时还原原文。
- DeepL、Google Cloud、Microsoft 翻译，以及自定义兼容 Chat Completions 端点；保留 DeepSeek、智谱、小米和 MiniMax。
- TXT / Markdown / HTML / DOCX / ePub / PDF / SRT / VTT 本地导入、翻译和导出。PDF.js 真实提取 / 渲染，扫描页视觉 OCR。
- 批量图片 OCR、区域与译文编辑、覆盖 PNG 导出、页面图片右键入口与圈选截图。
- 可读网页字幕双语显示、字幕文件翻译、本地音频转录；视频右键可主动开启标签页音频识别（需小米 MiMo）。
- Google Docs 导出 DOCX、本机 Zotero 索引文字只读翻译。
- 单词本搜索、全部遇见记录、JSON 备份合并、CSV / Anki 导入格式、删除与撤销。语境释义、音标和系统朗读。

## 更新

备份词库后，把 ZIP 解压覆盖原扩展目录，在 `chrome://extensions` 重新加载 Milo，再刷新网页。工具栏 → **工具与阅读设置** 或 `Alt+Shift+M` 打开工作台。原有密钥和词库继续保留。

## 实现边界

PDF 导出采用原页与译文对照，不含专业原版面重排；图片覆盖采用采样底色，不含背景修复。字幕依赖可读字幕或 MiMo 音频识别，分段存在延迟，平台与 DRM 可能限制采集。传统翻译服务和 AI 的实际语言 / 模型能力由账户决定；不附赠 API 额度。

164 项自动测试、lint、类型检查、build 与锁定依赖安装通过。隔离 Chromium 验证动态正文、仅译文恢复、三空格输入、划词、真实 PDF.js、DOCX/ePub/SRT 导出、模拟 OCR、可读字幕、真实圈选截图和词库备份 / 撤销。服务响应为模拟；实际 API 账户、在线 Google Docs / Zotero 与标签页音频采集未宣称已实测。
