# Milo v0.5.2 · 视频下方的一键字幕翻译

在 YouTube / X 看视频时，可以直接点击视频下方的 **字幕翻译** 按钮开启双语字幕，再点一下关闭。

- YouTube 尝试打开 CC；隐藏重复原字幕，关闭时恢复原字幕状态。
- X 每个视频都有独立入口，切换时只翻译选中的视频，不把不同视频的字幕混在一起。
- 容器全屏时保留按钮，滚动 / 缩放时字幕跟随视频。
- 新加载视频自动出现入口，移除选中视频后停止任务。
- 相同字幕不重复请求，短暂等待字幕稳定后再翻译，关闭会取消未完成请求。
- 没有可读字幕时提示等待 / 开启 CC；不自动上传音频。

本版依赖原生 TextTrack 或页面可读字幕，画面里烧录的文字不能直接读取；无字幕音频仍使用现有右键入口，需单独配置 MiMo。浏览器直接对 video 元素的原生全屏与播放器容器全屏不同，前者受原生控件限制。平台 DOM 变化可能需要后续适配。

170 项自动测试、lint、类型检查和构建通过。隔离 Chromium 的 YouTube / X 结构示例验证按钮、开启 / 关闭、CC 恢复、双语显示、容器全屏、多视频切换、页面滚动、动态插入、无字幕提示与请求去重；原有桌面链路回归通过。使用本地模拟 API，无真实服务账户或私人视频。

更新后在扩展管理页重新加载 Milo，并刷新 YouTube / X 页面。已有词库与密钥保留。
