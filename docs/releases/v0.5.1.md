# Milo v0.5.1 · 更顺手的文本翻译工作台

优化文本翻译界面的排版、状态与交互，保留 Milo 的米白与绿色风格。

- 侧栏按翻译工具、我的积累、偏好设置分组，支持地址定位与浏览器前进 / 返回。
- 原文与译文语言放到编辑区顶部，常用语言单独分组；指定原文语言后可交换语言，完成的译文也可带回原文区。
- 当前服务入口、示例、清空、字数、复制反馈与翻译按钮放到对应位置。
- 支持 ⌘ / Ctrl + Enter 翻译、Escape 停止；等待、失败、重试与完成状态清晰显示。
- 修改原文或语言会取消旧请求，旧译文标记待更新并禁止复制，防止误用；迟到结果不会覆盖新草稿。
- 工作台内切换页面保留文本草稿，离开文本页停止请求；草稿不写入永久存储。
- 改善笔记本和窄窗口布局，未配置密钥时提供配置入口。

165 项项目自动测试、lint、类型检查和构建通过。隔离 Chromium 验证配置引导、快捷翻译、复制、语言交换、取消、草稿保留、错误重试与响应式布局；使用本地示例和模拟 API 回复。

更新时覆盖原目录，在扩展管理页重新加载，再刷新旧工作台页面。已有词库和 API 配置保留。
