# Milo Browser Extension v0.2.4

**别人翻译完就结束，Milo 翻译完才刚开始。**

## 本版可以做什么

- 划选英文单词，显示中文释义、词性和原句。
- 一键收藏词条，同时保存原句、网页标题、URL 与时间。
- 再次保存同词时追加 encounter 并增加遇见次数。
- `⌘ A` / `Ctrl+A` 在英文段落下直接显示中文；再次按下恢复。
- X / Twitter 只翻译主栏正文，跳过导航、账号、互动与侧栏。
- 使用自己的 DeepSeek API Key，本地缓存、请求去重与优先级排队减少重复调用。
- 使用新的 Milo 鼹鼠图标，补齐中英文仓库介绍与功能配图。

## 安装

1. 下载下方 `Milo-Browser-Extension-v0.2.4.zip` 并解压。
2. Chrome 128+ 打开 `chrome://extensions`，启用开发者模式。
3. 点击「加载已解压的扩展程序」，选择含 `manifest.json` 的目录。
4. 在工具栏 Milo 中填入自己的 DeepSeek API Key。

[完整安装教程](https://github.com/libuyi543-lang/milo-browser-extension/blob/main/docs/INSTALL.md) · [功能展示](https://github.com/libuyi543-lang/milo-browser-extension#看看它怎么用)

## 数据与边界

当前词条只保存在浏览器本地，手机同步、账号、复习和数据导出尚未实现。卸载会删除本地数据。API 调用由自己的 DeepSeek 账户付费，取消已发出的请求仍可能收费。

尚未上架 Chrome Web Store；PDF / OCR / 图片文字不在本版范围。滚动新加载的正文可恢复后重新翻译。
