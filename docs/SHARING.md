## 一句话

别人翻译完就结束，Milo 翻译完才刚开始。

## 中文介绍，可直接分享

我做了一个英文阅读插件 Milo。遇见陌生词，划一下看释义，点「加入 Milo」，连同原句和网页来源一起留下。下次再遇见，次数 +1。

想看整篇？Mac 按 ⌘ A，Windows 按 Ctrl+A，中文直接出现在英文段落下面。看 X 时，只翻译正文，不把导航和侧栏也翻一遍。

当前支持 Chrome 开发者模式安装，支持 DeepSeek、智谱、小米 MiMo 和 MiniMax，使用自己的 API Key。词条保存在本地，手机同步还在后续计划中。

源码与安装包：https://github.com/libuyi543-lang/milo-browser-extension

## English

Meet Milo: an English-to-Chinese reading extension that saves words with their original sentence and page source. Repeated encounters become part of your vocabulary history. Read Chinese directly below English paragraphs, without leaving the page.

Chrome Developer mode installation, bring your own DeepSeek / GLM / Xiaomi MiMo / MiniMax key, local-first storage. Mobile sync is planned, not yet available.

https://github.com/libuyi543-lang/milo-browser-extension
