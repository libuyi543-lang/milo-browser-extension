# P0 首次使用观察记录

状态：**等待真实新用户参与**。本文件是可直接执行的测试单，不代表已经完成真人测试。内部隔离浏览器走查见 `scripts/test-p0-first-run.js`。

## 给参与者的任务（只读出这一段）

> 请在给定英文网页里找到一个不熟悉的单词，弄清词义并保存。之后请找到刚保存的词，确认它来自哪个句子。按照你平常使用浏览器的方式操作；如果遇到问题，可以说出你预期下一步会发生什么。

主持人只提供已安装 Milo 的全新 Chrome 配置和一篇可阅读的英文网页。**不解释划词、扩展图标、设置入口或单词本位置**，也不预填 API 密钥。测试用密钥由主持人准备，参与者看到设置引导后才提供；不得录屏或记录密钥本身。

## 当前内部走查（非真人可用性测试）

隔离配置的操作路径：**划选单词 → 点击配置 AI 服务 → 输入测试密钥 → 保存并使用 → 再划选单词 → 加入 Milo → 打开单词本**。共 7 个主要交互动作，其中重新划词是当前路径中的额外步骤。代码自动核对了词义、原句、保存结果、回看，以及无密钥时设置入口可打开。AI 返回由本地模拟；未验证真人是否理解按钮或愿意继续配置。

潜在停顿点：用户从设置页返回后需要再次划词；浏览器图标与单词本位置对首次用户可能不明显。记录真实观察后再决定是否加入自动回到待保存单词的流程。
